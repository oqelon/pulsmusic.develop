# Миграция «Пульса» с Electron на Tauri 2 — статус

Статусы: NOT STARTED · IN PROGRESS · NEEDS TESTING · COMPLETED · BLOCKED.
«COMPLETED» ставится только после фактической проверки на Mac владельцем проекта.

Основная тестовая платформа: **macOS, Apple Silicon (arm64)**. Windows-сборки (когда появятся) собираются в CI, но
протестированными не считаются.

## Решение владельца (22.11.2026)
«У нас только Tauri теперь, мы на него переходим». Новые правки интерфейса делаются для Tauri; Electron-версия
остаётся без изменений и не удаляется до полного завершения тестирования Tauri (прежнее условие).
Интерфейс для Tauri собирается из исходников (`app-dist.zip`), правки только для Tauri включаются по `window.__TAURI__`.

## Правила этапа
- Дизайн «Пульса» не меняется, интерфейс не переписывается: Tauri-сборка использует тот же `dist/`, что и Electron.
- Electron-версия, её выпуск обновлений, сайт и данные пользователей не затрагиваются. Тестовые сборки —
  только предварительные релизы `tauri-test-N` (не попадают в `releases/latest`).
- Тестовая сборка имеет свой идентификатор `ru.pulse.desktop.tauritest` и свою папку данных.
- Изменения звуковой системы — только после согласования.
- WASAPI Exclusive, ASIO и нативный аудиодвижок — вне миграции (будущий проект PULSE Audio Engine).

## Этап 3 — звук через Rust

Решения по итогам этапа 2 (согласовано 22.11.2026: «делай как считаешь нужным»):
- WebM через эквалайзер молчит → вариант А: для своих WebM-файлов не подключать эквалайзер (делается на этапе 6
  вместе со своей музыкой); позже — вариант Б (перекладывать WebM в OGG на лету).
- Список устройств вывода недоступен → вариант А: звук идёт на системный выход, переключение — в «Пункте
  управления» macOS. Вариант Б (список устройств из macOS через Rust) — по запросу.

Что сделано:
- `yastream.rs` — перенос `yastream.js`: реестр ссылок (только https-домены Яндекса), запрос к серверу кусками
  по 2 МБ, запасные ссылки, расшифровка AES-128/256-CTR с любого места, определение формата (FLAC/AAC/MP3,
  частота, разрядность), команда `ya_fmt`. Прямое соединение без прокси — как в Electron.
- `localfile.rs` — отдача своих файлов и обложек: обычный файл, кусок образа (ISO), «сырой» звук CD как WAV.
- Юнит-тесты (`cargo test` в CI): Range, расшифровка против векторов Node.js, определение формата, весь путь через
  локальный HTTP-сервер с проверкой байт в байт, куски образа CD.
- Лаборатория: раздел «Этап 3» — зашифрованные потоки как у Яндекса, сверка байт в байт, формат; демо-треки
  в интерфейсе «Пульса» играют через `pulseya://` и `pulsefile://`.
- `lab.rs` — тестовый сервер только для этой сборки, перед выпуском убирается.

Отличие от Electron: ответ своей схемы в Tauri отдаётся целиком, а не потоком, поэтому большие запросы режутся на
куски (Яндекс — 2 МБ, свои файлы — 4 МБ). Это заменяет прежнее ограничение «не быстрее 3 МБ/с».

Не входит в этап 3 (этап 6): разбор папок, теги, CUE, ISO, APE/WavPack (декодер), куски для записи CD (`?s=&e=`).

### Диагностика (tauri-test-4, 22.11.2026) → исправление (tauri-test-5)
- Причина «не играл 24/96»: плеер WebKit (AVFoundation) просит звук явными кусками («bytes=44-428452», ~400 КБ),
  а программа отвечала не больше 256 КБ. Недостающее AVFoundation НЕ дозапрашивает — в звуке дыра, плеер стоит.
  С кусками 2 МБ всё играло (до звука 50–60 мс, как у файла целиком). Исправлено: явный запрос отдаётся целиком
  (pulseya, pulsefile, pulsetest); открытый («bytes=a-») — по-прежнему кусками.
- Найдено попутно: перед звуком AVFoundation делает ~70 крошечных запросов (4–8 байт) — разбор MP4. С настоящим
  Яндексом каждый был бы отдельной поездкой по сети (50–150 мс) → старт трека на секунды. Добавлен кэш: у сервера
  берутся блоки по 256 КБ, расшифровываются и держатся в памяти (до 24 МБ на трек, 4 последних трека); мелкие
  запросы отдаются из него. Юнит-тест: 68 мелких запросов → к серверу 1–2.
- Opus: на 3-минутном файле перемотка к 10/50/90/97% — работает. Сбой на 10-секундном файле — особенность теста
  (перемотка почти в самый конец). COMPLETED.
- В лаборатории: замер с «сетью +80 мс на запрос», как с настоящим сервером.

## PULSE Audio Engine (задание владельца 22.11.2026: полная замена звука на нативный движок)

- `src-tauri/src/engine.rs` — движок: голоса (у каждого поток декодирования Symphonia, пересчёт частоты Rubato,
  буфер ~0,35 с), вывод CPAL с смешением голосов, общая шина: предусиление → 10 полос EQ (RBJ, как BiquadFilter) →
  лимитер. Перемотка: буфер голоса сбрасывается сразу, вывод не берёт звук, пока декодер не встанет на новое место
  (точная перемотка — с пропуском до нужного кадра). Громкость, пауза, старт, перемотка — с плавностью 6 мс.
  Скорость (для «Искры») — через ресемплер. Устройство: системное (следит за сменой) или выбранное.
  События окну: loaded / time / waiting / playing / ended / error.
- `src/services/engineAudio.js` (исходники интерфейса) — EngineAudio с API <audio> для player.js; плавный переход
  — второй голос; формат, которого нет в движке (Opus/WebM и др.), играет обычный <audio> внутри того же объекта;
  живой фон и визуализаторы — анализаторы по звуку общей шины движка; список устройств — от движка;
  «Сейчас играет»/медиаклавиши — беззвучный <audio>, пока играет движок.
- `player.js`: 6 точечных правок под флагом ENGINE (только Tauri); Electron-версия не меняется.
- Отключить движок (на случай проблем): localStorage `pulse.engine = off` → прежний <audio>.
- Проверка в CI (сборка 20, macOS arm64): 15 тестов Rust пройдены, в том числе `seek_is_exact_and_flushes`
  (после перемотки в буфере только звук нового места, позиция точная), `decode_formats` (MP3, AAC, FLAC 16/44 и 24/96,
  FLAC в MP4, ALAC, WAV, OGG, AIFF), `eq_flat_is_transparent`. Найдено: FLAC 32 бит Symphonia не декодирует —
  такой поток уходит в <audio>.
- Статус: **НУЖНА ПРОВЕРКА НА MAC** (сборка tauri-test-20). Работающим не считается до проверки владельцем.

## Этап 5 — перенос данных из Electron (22.11.2026)

- Решения владельца: перенос — сам при первом запуске; Electron-версия остаётся установленной до конца проверки Tauri
  (её данные только читаются). При совпадении записей побеждают данные Electron; записи, которые есть только в
  Tauri-версии, остаются; прежнее состояние Tauri сохраняется для возврата.
- `src-tauri/src/ldb.rs` — чтение localStorage Chromium (LevelDB: журнал + таблицы, Snappy) без сторонних

  150 КБ значение, кириллица, эмодзи).
- `src-tauri/src/migrate.rs` — копия Electron (`Local Storage`, `secure-token.bin`, `social.bin`,
  `local-library.json`, `local-covers`, `window.json`, `perf.json`, `online-id`) → `migration/backup-<время>/electron`
